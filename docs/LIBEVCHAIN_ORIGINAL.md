# libevchain original-source note

The Python source files under `src/libevchain/` are copied from the supplied COMP3988 evidence-chain package without source-code edits.

CS55-1 code is kept separately under `src/cs55_demo/`. Any project-specific custom types or workarounds are implemented there rather than by editing `libevchain`.

The original package README and pyproject metadata are preserved as:
- `docs/libevchain_README_original.md`
- `docs/libevchain_pyproject_original.toml`
